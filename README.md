# JSON Deep Path Reader

Read a safe dotted own-property path from JSON and fail cleanly when any segment is missing.

Generated by MiniMindsLab 02.13 GitHub Action Factory.

## Usage

```yaml
- uses: ./path-to-action
  id: miniminds
  with:
    payload: '{"value":{"a":{"b":{"c":7}}},"path":"a.b.c"}'
- run: echo '${{ steps.miniminds.outputs.result }}'
```

Runtime: Node 24. No external dependencies. No network access.
